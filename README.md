# Developer Portfolio & Services

This is a personal portfolio and freelance services web application built as a web development assignment. I created it to showcase my projects, highlight my background in software development, and provide interactive features.

##  Tech Stack
- HTML5
- CSS3
- JavaScript

## Live Demo
You can view the live project hosted on GitHub Pages here: https://nimrasultan2.github.io/web-projects

## Features
- **Dynamic Services & Cost Estimator:** Allows users to select custom freelance services and instantly calculates the total cost.
- **Age-Based Discount Calculator:** Automatically calculates the user's age from their birth year and checks for special discount eligibility.
- **Interactive Contact Form:** Includes live input validation, success messaging, and a character counter for special instructions.
- **Portfolio Filter Tabs:** Filters featured projects dynamically by category (Web Dev vs. Software/DB).
- **Light/Dark Mode Toggle:** Easily switches between light and dark themes using custom CSS variables.
- **Business Hours Status:** Automatically checks the current time and displays whether the developer is currently open for inquiries.
